# طالب علم حاضری

اردو-speaking اساتذہ کے لیے ایک سادہ موبائل-فرینڈلی attendance ایپ۔

## فیچرز

- طالب علم کا نام شامل کریں۔
- ہر طالب علم کو حاضر یا غیر حاضر نشان لگائیں۔
- حاضر، غیر حاضر، اور کل طلبہ کا خلاصہ دیکھیں۔
- ڈیٹا براؤزر کے `localStorage` میں محفوظ رہتا ہے۔

## چلانے کا طریقہ

`index.html` کو براہ راست براؤزر میں کھولیں، یا مقامی سرور استعمال کریں:

```bash
python3 -m http.server 8000
```
